Open charts in the TradingView app

iPhone doesn't let web pages open the TradingView app directly, so a tiny Apple Shortcut does it. Make it once (1 minute):

  1. Open the Shortcuts app → tap + (top right).
  2. Tap the name at the top → Rename → type exactly TradingView Chart.
  3. Tap Add Action → search Open URLs → add it.
  4. Tap the blue URL word in that action → choose Shortcut Input.
  5. Tap Done.

Already made it with Open App? Open the shortcut, remove that action (✕) and do steps 3–4.

From then on one tap opens the stock's chart in the TradingView app. The first time, iPhone asks "Open in Shortcuts?" — tap Open.
